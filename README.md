# RFD Classification Machine Learning Project

## Overview
This project is a Machine Learning Classification system developed using Python and Jupyter Notebook. The main objective of the project is to classify and analyze dataset records using multiple machine learning algorithms and compare their prediction performance. The project includes data preprocessing, exploratory data analysis, feature engineering, model training, testing, and evaluation.

## Features
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Selection and Engineering
- Classification Model Training
- Accuracy and Performance Evaluation
- Prediction and Result Analysis
- Data Visualization using Graphs and Charts

## Machine Learning Algorithms Used
- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Naive Bayes

## Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Workflow
1. Import Dataset
2. Data Cleaning and Transformation
3. Exploratory Data Analysis
4. Feature Engineering
5. Train-Test Split
6. Model Training and Evaluation
7. Prediction and Accuracy Comparison

## Objective
The goal of this project is to build an efficient classification model capable of analyzing data and generating accurate predictions using supervised machine learning algorithms.
